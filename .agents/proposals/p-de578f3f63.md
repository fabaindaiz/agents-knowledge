`bundle.py new entry --log` cannot read a carrier log whose format block sits under a heading without the word format (a how-to-log heading) and whose fields are bulleted bold labels, and it always writes a level-two heading where the log uses level three; in those carriers an agent writes the entry by hand and copies only the minted id. The tool should take the format from the log's reference block whatever its heading is called, read bulleted fields, and keep the log's heading level.

## Evidence

Two carriers updated on 2026-10-07 have logs of exactly that shape; both entries were written by hand, and both carriers' `close` skill now says to run the command without writing and copy its id.
