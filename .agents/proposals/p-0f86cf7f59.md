`release.py align` compares each carrier's `SHA256SUMS` with the home's working release, not with the tagged release the carrier holds, so as soon as the home builds anything unreleased every carrier reads as not aligned, although each still equals its tag exactly. It should compare against the tag of the version the carrier is registered at.

## Evidence

In one meta-session, two tool fixes were built in the home after a release was carried; a later `align` then failed all six carriers on that release, each of which matched the tag file for file when compared by hand.
