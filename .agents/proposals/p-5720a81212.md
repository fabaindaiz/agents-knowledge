`bundle.py carrier-id --mint` writes `upstream = ""` into a new carrier's file, the value the bundle's README reserves for the home repository; a bootstrapped carrier then claims to be a home until someone notices. Minting should write the home's id, or leave the key out and let verify ask for it.

## Evidence

Of two repositories bootstrapped the same day, one ended with the empty value and was corrected by hand to the home's id that its sibling carriers carry.
