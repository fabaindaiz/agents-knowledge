A carrier worked in a git worktree, with its development environment installed editable from the main checkout, runs its type-check ratchet against both trees at once and reports spurious new and gone errors. The method's advice on working in a worktree should say to run such checks from an environment bound to that worktree, or to read their result as unproven.

## Evidence

In one bootstrap done in a scratch worktree, the existing environment's type checker saw the source twice and reported four new and three gone errors, all from the worktree's own templates; the new files checked clean alone.
