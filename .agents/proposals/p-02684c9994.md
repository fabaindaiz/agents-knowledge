A carrier's own audit that reads a file the release generates by its layout (the knowledge index's phase table read through its card links) breaks when the release changes that layout, while `bundle.py verify` stays green; an update's pre-carry review should run the carrier's own audit over the new release in a scratch copy, which is how this was found.

## Evidence

One carrier on 0.0.25 read the index's phase rows only through card links; the 0.0.27 index lists slugs instead, and a scratch copy with 0.0.29 failed that audit on every note (about fifty failures) with `verify` passing. Found by the read-only execution review before the release was carried.
