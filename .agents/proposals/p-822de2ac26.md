A search for carriers reads every branch of every repository on the machine, not only the working tree: a repository whose bundle lives on a branch that is not checked out has no bundle folder on disk, and a search of the filesystem passes it by. For each git repository, list the branches (local and remote) that hold a bundle and at which version, and treat the one the team integrates the bundle on as the carrier's. Stops applying where every carrier keeps its bundle on its default branch. Costs one read per branch.

## Evidence

The same meta-session that found five unlisted carriers by searching for bundle folders missed two more: their bundles lived on dedicated branches while the working copies were on other branches without one. Both were already in the registry at an older release and were written off as "not on this machine"; the owner named them as the first to update. A listing of each repository's branches for a bundle header found them. Literature: none.
