Before a written procedure is released, one agent runs it from the document alone, on a disposable copy, and reports every point where it had to guess: tests prove the tools, not that the words lead to them. Stops applying to a procedure that only calls one tool whose refusals say what to do. Costs one agent run on a copy.

## Evidence

A dry run of a harvest procedure by an agent, after every tool test passed, ran each command first time and still guessed three times: work left by an earlier run, whether a date bound was inclusive, and how to extend an entry that had no identifier. Each became a sentence in the procedure. Literature: usability testing of written instructions (think-aloud protocols) is established practice; none known for agent procedures specifically.
