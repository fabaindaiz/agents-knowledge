The `close` skill should know the state "ready for review": where a host reserves merging and closing to a person, the agent prepares the evidence (gates green, the pull request body, the summary for the work item's author), moves the item to review, and stops; after a person approves, it merges, removes the worktree before deleting the branch, and closes the item. The skill's base names the stop; the carrier's own closing procedure, where it has one, wins.

## Evidence

The closing procedure several carriers share states that an agent never closes a ticket nor merges on its own initiative; the method's `close` merges or pushes only when asked but has no stop at ready, and one carrier's execution review found its own closing procedure and the skill unordered.
