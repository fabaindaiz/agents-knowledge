Before a delegated agent is launched, the session says its rough cost (tokens by order of magnitude, wall time) and gives it the cheapest model the task allows: a mid-size model for research, reading and analysis, a small one for mechanical counting and format checks, the main model only for adversarial judgement. A delegation priced in advance is one the human can stop; one launched unpriced on the main model is where a session's cost goes unseen.

## Evidence

The home's own usage, measured over one week (`meta/decisions.md`, d-5ed7e8-cdf1f3): sessions heavy with subagents made up most of the owner's usage, much of it from research agents run on the main model in one long session. Since that decision, this repository's sessions name the model and the cost of each delegation before launching it; on 2026-10-08, about thirty delegated runs (research, citation checks, scenario tests, fresh reviews) ran on a mid-size model, each priced first. One repository, one owner.
