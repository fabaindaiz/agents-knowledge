# Proposal: researcher-returns-its-report-in-the-reply

The researcher agent is read-only by design (its hook refuses every write but a download into its temporary folder, and it has no write tool), so a brief that asks it to write its findings to a file loses them: the agent can only return them in its reply. A delegation to the researcher must ask for the report in the reply, sized to fit it; a long document is written by the delegating session from that reply, or delegated to a write-capable agent with the same source rules.

## Evidence

One occurrence in the home on 2026-11-25: a researcher briefed to write a long findings file to a scratch folder returned a short report instead, saying its shell refused the write, with only two claims verified; the same question re-run on a general agent with write access produced the full document in minutes. The agent's own definition says reading only; the brief contradicted it.
