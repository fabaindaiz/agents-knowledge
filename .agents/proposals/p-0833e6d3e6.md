# Proposal: a-check-must-be-seen-to-fail

A new warning can be green because it is blind, and the way to see it is to compare the count of subjects the check recognised with the count of subjects known to exist. The warning for a cited record id defined nowhere fired 95 times on first run with nothing real among the findings: the check accepted a definition only in a table row or a heading, and this repository defines its roadmap items as list bullets. Teaching it that shape moved the recognised definitions from 155 to 225 and the warning to zero. An earlier release had taught the same check the heading shape. Both were partial blindness of the same recogniser, and neither was visible from the warning's output, only from the ratio of what was found to what exists. The note's boundary should read: when a check classifies subjects by shape, report how many it recognised per shape, and compare the total with an independent count.

## Evidence

One repository of the kind that stores its records in several document shapes (table rows, headings, bullets). Figures from the closing review's recorded experiment of 2026-10-15: 95 findings none real; definitions 155 to 225; warning to zero. The previous occurrence in the same check is the heading shape, fixed in an earlier release. The experiment was recorded as confirming the note and adding a second occurrence to a boundary a run of 2026-10-01 had named. Literature consulted: none beyond the note's own.
