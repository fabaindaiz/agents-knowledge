An artefact a person interacts with through the agent (a guide, a ready-made prompt, a question flow, an advisor's answer) is designed the way a user-facing flow is: its users and goals, the ideal path, every way it goes wrong listed before any is handled, and the handling choices walked with the person one per turn, before it is written. Without that walk the agent writes the ideal path and the person finds the gaps in use.

## Evidence

2026-10-08, in the home: a session advisor and a guide to starting each process were designed this way at the owner's request. The walk of the advisor's flow listed some twenty cases and three handling choices the owner decided (a process in course, a host without skills, an action already declined). Reading the finished guide back with the owner, one decision per turn, found four more, the largest a missing step: consulting the knowledge index before a design decision, the same gap a pilot in another repository had shown. Each kept case became a scenario the skill was tested against before and after it was written. One repository, one owner.
