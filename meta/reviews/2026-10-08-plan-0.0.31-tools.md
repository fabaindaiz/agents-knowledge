## Global Constraints

- Edit originals only: `sources/`, `meta/`, root files. Never a file under `.agents/` but `carrier.toml` and proposals.
- Standard library only; Python 3.11 or newer.
- English only, no project nouns, nothing that identifies a carrier (principle 20); `bundle.py privacy` 0 FAIL.
- The gate, before every commit: `python3 meta/tools/release.py build && python3 meta/tools/release.py check && NO_COLOR=1 python3 -m unittest discover -s meta/tests -t .`
  (`NO_COLOR` until Task 1 lands).
- Conventional Commits; no attribution line (`bundle.py trailers`).
- One branch and worktree per task, named `fix/<item>`; after the gate and the task's review, fast-forward `main`
  (`git push origin HEAD:main`, never force) and remove the worktree.
- Record ids only from `bundle.py id`.

## Review Focus

1. **A quote that shares a phrase with the bundle but is not one of its sentences.** It still warns: D1 exempts the whole
   quoted span found verbatim, never a span that merely contains bundle words (Task 3, test 3).
2. **A gather over a carrier with no bundle on disk.** The report says *not read* for it, so its proposals are never
   dropped in silence (Task 4, test 4).
3. **`export --replace` over a folder holding a file neither release lists.** It refuses and removes nothing (Task 6,
   test 2).
4. **`$CLAUDE_JOB_DIR` unset, missing, or inside the repository.** Not accepted as a scratch root (Task 5, test 2).
5. **A skill declined after it was installed.** `install-skills` never deletes it; it says it is installed though
   declined, and `--check` warns instead of failing (Task 7, test 2).
