# Proposals received

Every proposal a carrier offered that `release.py intake` took in, by its id, the release it was taken in at, and where it went. `release.py build` publishes this table as `.agents/proposals/RECEIVED.md`, and each carrier removes the proposals listed there with `bundle.py proposals --prune`. Ids only: which carrier offered a proposal is never written here or anywhere in the home. Rows are appended by `intake`, never edited.
